# Frontend Design Skill (Anti-AI-Slop Standard)

## Core Philosophy
AI-built websites in 2026 suffer from a pervasive "sameness": generic purple gradients, the Inter font, and standard 4-card grids. This skill establishes hard guardrails and professional design directives.

## Rules & Constraints
1. **Typography Prohibition**:
   - Strictly avoid default AI typography (`Inter`, `Roboto`, `Arial`).
   - Use distinctive, deliberate font pairings:
     - Headings: `Outfit`, `Syne`, `Space Grotesk`, `Cabinet Grotesk`, `Clash Display`, or `Plus Jakarta Sans`.
     - Code/Telemetry: `JetBrains Mono`, `Space Mono`, or `Fira Code`.
2. **Layout Prohibition**:
   - Never build UIs purely from uniform 4-card grids or generic SaaS feature blocks.
   - Use dynamic layouts: asymmetrical Bento grids, split command centers, high-density data HUDs, and sidebar operational consoles.
3. **Color & Gradients**:
   - Ban generic purple/indigo gradients on dark backgrounds.
   - Use purpose-driven palettes: Cyber Slate, Tactical Emerald, Solarized Navy, Tokyo Night, Monokai Pro.
   - Use subtle noise textures, delicate 1px borders with optical glow, and rich dark mode contrasts (#080b11, #0d131f).
