# Accesslint Accessibility Skill

## A11y Standards
1. Contrast ratio must exceed 4.5:1 for body copy and 3:1 for large headings.
2. Interactive controls must have visible `:focus-visible` rings (`outline: 2px solid var(--accent-cyan)`).
3. Semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
