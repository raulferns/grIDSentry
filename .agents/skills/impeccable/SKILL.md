# Impeccable Design Polishing Skill

## Visual Polish Standards
1. **Vertical Rhythm**: Maintain strict 4px / 8px spacing multiples across all padding, margins, and gaps.
2. **Border Luminance**: Use dual-layered borders: 1px subtle border (`rgba(255,255,255,0.08)`) with an inner box-shadow (`inset 0 1px 0 rgba(255,255,255,0.06)`).
3. **Optical Balance**: Align icons and text caps optically rather than purely mathematically.
4. **Micro-interactions**: Hover transitions must be under 180ms with `cubic-bezier(0.16, 1, 0.3, 1)`.
